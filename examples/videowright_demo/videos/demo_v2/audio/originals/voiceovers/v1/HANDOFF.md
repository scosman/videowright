# Voiceover v1 — portal handoff

The demo_v2 voiceover is generated by the user in the ElevenLabs web portal (no API key in the
build environment). Two files come back: `raw.mp3` and `raw_stt.json`. The build agent then runs
`retime check` + `retime apply` (see `generate.sh` steps 3) and syncs the result.

## Steps

1. **Text to Speech** → model **Eleven v3**, voice **Asher**, stability **Natural** (0.5).
2. Paste the text below exactly (the `[pause]` tags are intentional). Generate. If a take drops,
   repeats or mangles words, regenerate — takes vary.
3. Download the audio → save as `raw.mp3`.
4. **Speech to Text** → upload `raw.mp3` → when done, **Export → JSON** (not plain text: we need
   per-word timestamps) → save as `raw_stt.json`.
5. Put both files in this folder:
   `examples/videowright_demo/videos/demo_v2/audio/originals/voiceovers/v1/`
   (easiest: on GitHub, open this folder on branch `claude/brave-heisenberg-0ypj2b` →
   **Add file → Upload files**).

Don't adjust pauses in the portal — `retime apply` sets every pause to its exact length, and the
lengths can be re-tuned later from the same take.
