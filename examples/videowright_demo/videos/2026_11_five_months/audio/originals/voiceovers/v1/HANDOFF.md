# Voiceover v1 (the narration) — portal handoff

> Status: waiting for the take.

Generated by the owner in the ElevenLabs web portal (no API key in the build environment). Two
files come back: `raw.mp3` and `raw_stt.json`. The build agent then converts the STT export,
runs `retime check` + `retime apply` (which set every pause to its exact length), and syncs.

## Steps

1. **Text to Speech** → model **Eleven v4**, voice **Cosman-1**, speed 1.00, stability 50, similarity boost 75.
2. Paste the text below exactly. The `[pause]` tags are intentional, and `[warmly]` / `[excited]`
   are the only emotion tags (the voice beat shows them off). Generate. If a take drops, repeats
   or mangles words, or reads a tag aloud, regenerate: takes vary.
3. Download the audio → save as `raw.mp3`.
4. **Speech to Text** → upload `raw.mp3` → when done, **Export → JSON** (not plain text: per-word
   timestamps are needed) → save as `raw_stt.json`.
5. Put both files in this folder: `examples/videowright_demo/videos/2026_11_five_months/audio/originals/voiceovers/v1/` on branch `claude/quirky-keller-dcn7ld`
   (on GitHub: open this folder → **Add file → Upload files**).

Don't adjust pauses in the portal.
